# 微信跳一跳训练器

棋子离下一个台心还有多远，鼠标该按住多久？这个 Windows 项目从微信电脑版《跳一跳》的画面里找出棋子脚底和目标台心，把距离换算成蓄力时间。落地后，它再比较前后两帧，扣除镜头移动，用实际跳过的距离校准下一版模型。

实战最高分为 **15,677 分**，比上次发布的 14,419 分高 1,258 分（8.7%）。最高分出现在 03:21，之后另开的一局最后读到 252 分。这份快照收录了截至 2026 年 11 月 25 日 03:35（北京时间）的 **1,398 次起跳**和 **191 张训练画面**。可以直接用仓库里的数据比较模型，无需打开游戏。[最高分实战截图](跳一跳训练/成绩/实战_15677.png)

![一张实际训练样本，棋子站在右侧白色方台上，左上方橙色方台的白点是目标](跳一跳训练/视觉训练/画面/v0001.png)

图中这一步，程序从右侧棋子的脚底瞄向左侧橙色台面。按原窗口坐标换算，沿跳跃方向的距离约为 145 像素，随库蓄力模型给出的预测是 **0.477 秒**。

| --- | --- | --- |

| 蓄力模型晋级 | 新版用 459 个合格落点训练，与旧版在同一局随后发生的 12 跳上比较 | 平均绝对误差从 7.82 降到 7.67 毫秒，同批固定曲线为 8.46 毫秒 |
| 晋级后回测 | 用两版模型重新预测晋级后采集的全部 186 条合格实跳 | 旧版、新版的平均绝对误差分别为 3.19、3.22 毫秒。绝对误差的 90 分位从 6.38 降至 6.04 毫秒 |
| 新旧台心定位对比 | 69 张训练、32 张开发、89 张按时间留出的测试画面，另有 1 张重复。将两版模型分别应用于同样的 89 张测试图 | 76 张有标记图上的平均误差从 0.488 降到 0.324 像素（下降 33.5%），95 分位从 2.109 降到 0.584 像素。识别数从 61 增至 72，另外 13 张无标记图两版均未误报 |

**蓄力误差**衡量模型按实际跳跃距离推算的时长与真实按压时长之差。上表两次比较各自使用同一批数据，新版在晋级的 12 跳上平均误差较低，在随后 186 跳上主要改善了误差较大的一端。当前部署版使用 459 个样本训练，另一份用 651 个样本训练的候选模型已保存，截至快照时已积累同局验证样本 10/12 条，实跳仍使用部署版。[逐批记录](跳一跳训练/批次评估.jsonl) · [两版蓄力模型回测](跳一跳训练/蓄力版本对比.json) · [651 样本候选模型](跳一跳训练/候选模型/online-20261125-033446-274830.py)

**定位误差**以可见标记的颜色边界质心为参考。模型把握不足时沿用粗定位，该误差也计入平均值。两版的中位误差都接近 0.10 像素，新版主要改善了部分偏得较远的场景。它的最差一例出现在 v0143，沿用粗定位后偏了 8.63 像素，旧版在该图偏了 0.045 像素。实跳控制器在符合条件的普通平台上交替测试至多 2 像素的横向修正。目前两组各记录了 12 跳，单局涨分中的模型贡献仍难以量化。[逐图新旧对照](跳一跳训练/视觉训练/视觉模型同图对照.json) · [独立测试](跳一跳训练/视觉训练/独立测试.json) · [落地反馈](跳一跳训练/视觉训练/落地反馈.json)

## 离线复现

使用 Windows PowerShell 和 Python 3.12。先在仓库根目录创建环境并安装依赖。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

**预测一次蓄力。** 输入距离使用宽 543 像素的参考窗口坐标。随库模型在 85 至 285 像素内输出秒数，超出范围时由游戏主程序使用分段曲线。

```powershell
.\.venv\Scripts\python.exe -c "from jump_timing import predict_hold; print(round(predict_hold(145), 3))"
```

**重跑蓄力实验。** 脚本从早期日志还原 97 条距离和按压时长均有记录的样本，按时间顺序训练和验证，生成 `duration_validation.json` 与 `duration_mlp_offline.json`。其中 57 条滚动验证样本上，固定曲线和残差神经网络的平均绝对误差分别为 5.366 和 3.058 毫秒。

```powershell
.\.venv\Scripts\python.exe train_duration.py
```

**重跑台心定位实验。** 以下三步依次用早期画面拟合权重、评估留出画面、将预测与历史落地记录配对。原始坐标以 543 × 1029 的游戏窗口为准，换算到裁剪图需将横坐标减 4、纵坐标减 335。

```powershell
.\.venv\Scripts\python.exe ".\跳一跳训练\视觉训练\train_refinement.py"
.\.venv\Scripts\python.exe ".\跳一跳训练\视觉训练\evaluate_refinement.py"
.\.venv\Scripts\python.exe ".\跳一跳训练\视觉训练\feedback.py"
```

## 在微信里试跳

1. 在 Windows 微信电脑版打开《跳一跳》，进入能看见棋子和下一座平台的游戏画面。保持游戏窗口可见，窗口宽高比例接近 543∶1029。
2. 在 PowerShell 运行下面的命令，随后在 8 秒内切回游戏窗口。程序会按窗口标题查找游戏，并核对所属进程。一次试跳后，它会记录落点。

   ```powershell
   .\.venv\Scripts\python.exe jump_play.py --jumps 1
   ```

3. 要连续采集，运行以下命令。程序会在识别到结算页时重新开始，识别不确定时会停下。可在终端按 `Ctrl+C` 结束。

   ```powershell
   .\.venv\Scripts\python.exe jump_play.py --until-stopped --restart
   ```

新运行的逐跳日志写入 `runs/`。在线训练器从日志提取按压时长、镜头位移和落点，先训练候选模型，再用之后采集的同局样本评估。候选通过误差门槛后，才会替换实跳使用的 `jump_timing.py`。窗口被遮挡、最小化或比例差异过大时，需要先恢复游戏画面。
