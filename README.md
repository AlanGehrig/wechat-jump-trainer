# 微信跳一跳训练器

棋子离下一个台心还有多远，鼠标该按住多久？这个 Windows 项目从微信电脑版《跳一跳》的画面里找出棋子脚底和目标台心，把距离换算成蓄力时间。落地后，它再比较前后两帧，扣除镜头移动，用实际跳过的距离校准下一版模型。

这份训练快照记录了 **1,158 次起跳**，游戏中读到的最高分为 **14,419**。仓库提供实跳数据、模型权重和训练脚本，可以先离线复现实验，也可以在自己的游戏窗口试跳。

![一张实际训练样本，棋子站在右侧白色方台上，左上方橙色方台的白点是目标](跳一跳训练/视觉训练/画面/v0001.png)

图中这一步，程序从右侧棋子的脚底瞄向左侧橙色台面。按原窗口坐标换算，沿跳跃方向的距离约为 145 像素，随库蓄力模型给出的预测是 **0.477 秒**。

## 实测结果

| 实验 | 样本和方法 | 结果 |
| --- | --- | --- |
| 实跳采集 | 2026 年 11 月 25 日 03:18（北京时间）的数据库快照 | 1,158 次起跳，482 次取得落点测量，459 条通过训练筛选 |
| 蓄力时长 | 用 186 个合格落点训练，再用同一局随后发生的 12 跳比较模型 | 平均绝对误差从上一版的 4.61 毫秒降至 4.30 毫秒，同批固定曲线为 5.50 毫秒 |
| 白点定位 | 视觉实验用 69 张画面训练、32 张开发集画面评估，另有 1 张重复场景 | 在 21 张可见白点的开发图上，预测中心到参考中心的平均距离从 3.486 降至 0.096 像素。其余 11 张均未误报白点 |

最高分取自游戏窗口的分数读数。蓄力误差衡量模型预测与实际按压时长的差值。白点实验以标记的颜色边界质心为参考，开发集也参与了识别阈值选择。这组数字描述的是这批画面上的局部定位精度。白点细定位可在视觉训练目录独立复现，实跳主程序使用随库的基础视觉识别器。逐批结果见[蓄力评估记录](跳一跳训练/批次评估.jsonl)和[视觉开发集报告](跳一跳训练/视觉训练/开发评估.json)。

## 离线复现

使用 Windows PowerShell 和 Python 3.12。先在仓库根目录创建环境并安装依赖。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

**预测一次蓄力。** 输入距离使用宽 543 像素的参考窗口坐标。随库模型在 85 至 285 像素内输出秒数，超出范围时由游戏主程序使用分段曲线。

```powershell
.\.venv\Scripts\python.exe -c "from jump_timing import predict_hold; print(round(predict_hold(145), 3))"
```

**重跑蓄力实验。** 脚本从早期日志还原 97 条距离和按压时长均有记录的样本，按时间顺序训练和验证，生成 `duration_validation.json` 与 `duration_mlp_offline.json`。其中 57 条滚动验证样本上，固定曲线和残差神经网络的平均绝对误差分别为 5.366 和 3.058 毫秒。

```powershell
.\.venv\Scripts\python.exe train_duration.py
```

**重跑白点定位实验。** 脚本读取仓库里的裁剪图、粗定位坐标和标注，重新生成 `marker_weights.json` 和 `开发评估.json`。样本索引中的坐标以 543 × 1029 的原窗口为准，换算到裁剪图需将横坐标减 4、纵坐标减 335。

```powershell
.\.venv\Scripts\python.exe ".\跳一跳训练\视觉训练\train_refinement.py"
```

## 在微信里试跳

1. 在 Windows 微信电脑版打开《跳一跳》，进入能看见棋子和下一座平台的游戏画面。保持游戏窗口可见，窗口宽高比例接近 543∶1029。
2. 在 PowerShell 运行下面的命令，随后在 8 秒内切回游戏窗口。程序会按窗口标题查找游戏，并核对所属进程。一次试跳后，它会记录落点。

   ```powershell
   .\.venv\Scripts\python.exe jump_play.py --jumps 1
   ```

3. 要连续采集，运行以下命令。程序会在识别到结算页时重新开始，识别不确定时会停下。可在终端按 `Ctrl+C` 结束。

   ```powershell
   .\.venv\Scripts\python.exe jump_play.py --until-stopped --restart
   ```

新运行的逐跳日志写入 `runs/`。在线训练器从日志提取按压时长、镜头位移和落点，先训练候选模型，再用之后采集的同局样本评估。候选通过误差门槛后，才会替换实跳使用的 `jump_timing.py`。窗口被遮挡、最小化或比例差异过大时，需要先恢复游戏画面。
