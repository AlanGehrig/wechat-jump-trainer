# 本机台心标记定位模型

模型在现有台面识别给出粗略落点后，从周围画面寻找可见的椭圆标记。检测成功时给出全窗口像素坐标。画面尺寸为 543 × 1029，单次修正上限为 26 像素。模型可以弃权并沿用粗定位。

## 数据与标注

本机既有游戏截图共冻结 191 张，每张仅保留画布中横坐标 4 至 538、纵坐标 335 至 729 的区域。排除了结算界面，并按画布摘要和同一分数下的棋子位置去重。190 个场景进入分析。此处的“场景”是一次已观测到的台面布局。

视觉助手先逐张查看原色和局部对比度放大的目标图，识别可见标记。放大对比度可分辨仅有一级灰度差的浅色盘心。参考坐标由标记边界的质心独立测得。没有可见标记的场景用于检查误触发。用户和第三方标注员未参与此项标注。

69 个早期场景训练逻辑回归，含 49 个有标记台面。训练包含 375 个正位置和 18,514 个负位置。32 个较晚场景用于检查候选得分和设置接受阈值，随后三批按时间截取的 89 个场景作为留出集。所有画面与反馈均来自本机。

## 独立测试

| 指标 | 结果 |
| --- | --- |
| 有标记场景接受数 | 72 / 76 |
| 无标记场景误触发数 | 0 / 13 |
| 有标记台面平均定位误差 | 粗定位 3.329 px，精修 0.324 px |
| 有标记台面 95 分位误差 | 粗定位 11.294 px，精修 0.584 px |
| 15 个短跳的平均定位误差 | 粗定位 4.369 px，精修 0.168 px |
| 445 次预热单帧调用耗时 | 中位数 2.408 ms，95 分位 3.162 ms |

定位误差包括模型弃权后沿用的粗定位。短跳采用 543 像素宽窗口下轴向距离小于 115 像素的口径。13 个无标记场景限制了对其他台面皮肤误触发率的推断。模型得分描述局部图案匹配程度，游戏得分、全局台面识别以及跳跃时长分别由其他模块处理。

89 个留出场景均可唯一关联到持续游戏日志中的实际动作，86 次随后增加分数。64 个有标记场景还具有经镜头平移校正的落地观测。这些回放记录反映采集时正在运行的控制器；精修模块的实战效果需要部署后另行验证。

## 文件

- `jump_refinement.py` 和 `marker_weights.json` 用于本机推理。初始化一次 `MarkerRefiner()`，按帧调用 `predict(rgb_frame, (x, y))`。
- `标注.json` 和 `样本.jsonl` 记录逐图参考、分组与裁切。逐图复核选择保存在 `人工阅图.json`。
- `训练` 由 `train_refinement.py` 执行。训练只读取历史组和 A 组。B 组用于阈值设置。
- `独立测试.json` 及 `落地反馈.json` 保留逐样本结果，便于检查误差、弃权和反馈归属。
